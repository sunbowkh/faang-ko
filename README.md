# FAANG 기술면접 한국어 학습 노트

한국어로 FAANG / 빅테크 기술면접을 준비하기 위한 개인 학습용 웹앱입니다.

- 웹에서 보기: https://sunbowkh.github.io/faang-ko/
- 아이폰: Safari에서 열고 공유 버튼 → "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 기능

- NeetCode 150 / Blind 75 패턴별 문제 목록, 한국어 핵심 아이디어와 시간·공간 복잡도
- 패턴 치트시트 (파이썬 템플릿)
- 회사별 면접 형식과 2026년 변화 요약, 회사별 문제 목록
- AI 랩 면접 특징, 시스템 디자인 요약
- 복습 플래시카드, 진도 체크와 메모 (브라우저 localStorage에 저장)

### 원본에서 변경한 내용 (2026년 10월)

- 원본의 문제 목록, 회사별 면접 정보, 시스템 디자인 가이드를 한국어로 번역·요약하여 단일 HTML 웹앱으로 재구성
- 원본에 없는 내용을 새로 작성: 문제별 한국어 핵심 아이디어와 복잡도, 패턴 설명과 템플릿 코드, 면접 진행 팁, 면접 영어 표현
- 진도 체크, 메모, 플래시카드, 모바일(홈 화면 앱) 지원 추가
